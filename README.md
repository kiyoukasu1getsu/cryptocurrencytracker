# CryptoTracker — Трекер криптовалют на Swift/SwiftUI

Приложение для отслеживания цен на криптовалюты и управления портфелем инвестиций, разработанное на **Swift** с использованием фреймворка **SwiftUI** для iOS.

## 📱 Поддерживаемые платформы

- **iOS** 17.0+
- **iPhone** и **iPad**

## ✨ Возможности

### Отслеживание криптовалют
- Просмотр топ-50 криптовалют по рыночной капитализации
- Актуальные цены в реальном времени через CoinGecko API
- Отображение изменений цены за 24 часа с цветовыми индикаторами (зелёный — рост, красный — падение)
- Логотипы криптовалют
- Pull-to-refresh для обновления данных

### Управление портфелем
- Добавление монет в абстрактный портфель с указанием:
  - Количества монет
  - Цены покупки за 1 монету
- Автоматический расчёт:
  - Текущей стоимости позиции
  - Общей стоимости портфеля
  - Вложенной суммы
  - Прибыли/убытка в долларах и процентах
  - ROI (Return on Investment)
- Редактирование существующих позиций
- Удаление позиций (свайпом или через меню редактирования)
- Локальное сохранение данных (UserDefaults)

### Интерфейс
- Современный дизайн на SwiftUI
- Навигация через TabView (два раздела: "Криптовалюты" и "Портфель")
- Адаптивный интерфейс для iPhone и iPad
- Поддержка светлой темы
- Интуитивно понятный UX

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd CryptoTracker
```

### 2. Открытие проекта

Откройте файл `CryptoTracker.xcodeproj` в Xcode:

```bash
open CryptoTracker/CryptoTracker.xcodeproj
```

### 3. Настройка signing

В Xcode:
1. Выберите проект в навигаторе слева
2. Выберите таргет **CryptoTracker**
3. Перейдите на вкладку **Signing & Capabilities**
4. Выберите вашу команду (Team) из списка или добавьте свой Apple ID

### 4. Запуск приложения

- **На симуляторе**: Выберите устройство в списке устройств и нажмите `Cmd+R`
- **На реальном устройстве**: Подключите устройство к Mac, выберите его и нажмите `Cmd+R`

## 🌐 API

Приложение использует бесплатный **CoinGecko API**:
- **Endpoint**: `https://api.coingecko.com/api/v3`
- **Методы**:
  - `/coins/markets` — получение списка криптовалют с ценами
  - `/simple/price` — получение актуальных цен для портфеля

**Примечание**: CoinGecko API имеет ограничения на количество запросов. Для коммерческого использования рассмотрите возможность получения API-ключа.

## 📖 Как использовать

### 1. Просмотр криптовалют
1. Откройте вкладку **"Криптовалюты"**
2. Просматривайте список из топ-50 монет
3. Нажмите на любую монету для добавления в портфель

### 2. Добавление в портфель
1. Выберите криптовалюту из списка
2. Введите количество монет
3. Укажите цену покупки за 1 монету (в USD)
4. Нажмите **"Добавить"**

### 3. Управление портфелем
1. Перейдите на вкладку **"Портфель"**
2. Просматривайте общую стоимость, вложенную сумму и прибыль/убыток
3. Для редактирования нажмите на позицию
4. Для удаления свайпните влево или используйте кнопку в режиме редактирования
5. Потяните вниз для обновления текущих цен

## 🎨 Особенности реализации

- **MVVM архитектура**: Разделение логики (ViewModels) и интерфейса (Views)
- **Combine и async/await**: Современный подход к асинхронному программированию
- **UserDefaults**: Локальное хранение данных портфеля
- **SwiftUI**: Декларативный UI с поддержкой предпросмотра
- **EnvironmentObject**: Глобальное состояние для управления портфелем
